TRMNL markup, BRIEF §8: full, half_horizontal, half_vertical, quadrant (Framework 3.4, D18), portrait in every view. No literal words in templates (R13) except the error screen (TEXT_REQUIREMENTS). Design: `docs/DESIGN_PHILOSOPHY.md`, D19–D21.

## Files

- `src/`: the plugin in TRMNL's private-plugin export layout.
  - `settings.yml`: name, Polling strategy, the Polling URL, and the form fields (About This Plugin with the data credits (D20), Language en/de, Units Metric/Imperial, metric by default).
  - `shared.liquid`: goes in the **Shared** tab. Reads the two settings (an empty value counts as the default), defines the `ds_chain`, `ds_box` and `ds_error` templates, and one map script that allows several copies on a screen (mashups).
  - `full.liquid`, `half_horizontal.liquid`, `half_vertical.liquid`, `quadrant.liquid`: one per view. Each is a full-bleed map (`TRMNLMaps`, `outline` preset, integer zoom fitted to the whole path, D19) with the text box bottom left (D21).
- `polling_url.liquid`: the recipe's Polling URL (D18). Generated by `pipeline/downstream/site.py`
  with a fixed 7,200 slots (not the town count, which changes with GeoNames); tests fail if it or
  `src/settings.yml` is out of date. One line.
- `tools/render-check.mjs`: the render sweep (DESIGN_PHILOSOPHY §7).

## Render check

Needs `uv run python -m downstream.fetch framework` (Framework 3.4.0 CSS/JS, fonts, MapLibre 5.24.0 into `data/raw/framework/`) and a built site (`python -m downstream.site`).

```
cd recipe/tools && npm ci && npm run check                  # all cases
ONLY=Munich VIEW=full DEVICE=x_land npm run check           # a subset (also JOBS=n, DEBUG=1)
```

It renders every view (inside a real mashup for the smaller ones) on OG 1-bit, OG 2-bit, X landscape and X portrait, for 10 towns picked for their edge cases (among them Vihti and the two longest town lines) plus the error screen, in English/imperial and German/metric. Liquid is rendered by `render.rb` with Ruby Liquid (`gem install liquid`; 5.14.0 checked), the engine TRMNL runs; liquidjs, used at first, accepted a tag TRMNL rejected. Maps use Chromium's software WebGL. A case fails when:

- a map is missing, not built or not fully drawn, or its path isn't painted (the screenshot has no ink at 10 % or more of the visible path points);
- the path runs off the map or under the text box;
- the box leaves the map or covers the map's OpenStreetMap credit;
- text is cut (the Framework's clamp trimmed it, or it overflows). Exception: town lines over 45 characters (15 towns in German, 1 in English) may be shortened; they are counted, not failed.
- a case throws (Liquid error, timeout).

Screenshots and `results.json` go to `tools/out/` (git-ignored). TRMNL's tiles, glyphs and styles are fetched once by Node and cached in `data/cache/trmnl-maps/`, since Chromium's own fetches through the sandbox proxy failed and left maps half drawn. Before checking, it calls `TRMNLMaps.refresh()` as TRMNL's screenshot service does.

## Installing (not confirmed on TRMNL yet)

Create a private plugin with Polling strategy, paste the Polling URL, then paste each `.liquid` file into its tab (Shared, Full, Half horizontal, Half vertical, Quadrant) and add the form fields from `settings.yml`. Alternatively, zip `src/` and use TRMNL's plugin import; that path hasn't been tried.
